# Spectrum Updater 1.0 — build 15

Native macOS stock firmware updater for selected Eve/Dough Spectrum IPS profiles.

## Download

- `Spectrum-Updater-1.0-macOS.zip`: universal Apple Silicon/Intel app, start-here instructions, compatibility notice, and MIT license.
- `SHA256SUMS.txt`: checksum for the app ZIP.
- GitHub source archives: source code, guides, offline tests, and documentation images; these are not the app download.

Requires **macOS 13+**. The app is **ad-hoc signed and not Apple-notarized**. Follow the [opening/update guide](../UPDATE-GUIDE.md) if macOS asks you to approve it.

## Highlights

- Native one-page UI, automatic USB registry detection, and readable permanent diagnostics.
- Original vendor ZIP/BIN/USB-EXE imports; Windows installers are parsed as data, never executed.
- Exact stock release profiles for ES07D03, ES07DC9, ES07E30, and ES07D02.
- MStar scaler route with included secondary HDMI/bridge payloads.
- Separate VIA hub/PD routes with controller/layout checks and component-preserving flash plans.
- Verified durable backup before erase and final readback verification.
- Current-step-only progress indicator: Select monitor → Connect → Install → Finish.
- Stable log scrolling, green/red status with text markers, and path omission.

**No firmware binaries are bundled.** Obtain compatible original vendor files as described in [Firmware](../FIRMWARE.md).

## Validation and limits

The D03 scaler route has a prior reported successful physical flash on one unit. **Hub/PD updates, macOS paired-hub access, and updates on the other model units still require physical validation.** Protocol/import/CLI/backup/UI evidence is offline; it is not hardware certification.

D01, DCA, OLED families, arbitrary/modified images, unknown installed scaler versions, and unsupported chip/layout profiles are excluded. There is no separate raw-HDMI workflow or automatic whole-USB-chip restore. The release installs stock firmware and contains no custom blackout/wake fix.

Read [Compatibility](../COMPATIBILITY.md), [Validation](../VALIDATION.md), and [Recovery](../RECOVERY.md) before updating.

## Check the downloaded archive

In the directory containing the ZIP and checksum file:

```sh
shasum -a 256 -c SHA256SUMS.txt
```

The checksum establishes archive integrity, not successful device boot or improved monitor behavior.
